# Audit of every input (Phase 1, 2026-09-28)

Every number that enters a solve, with where the code reads it, its source and its class.

**Classes:**
- **V (verified):** checked against the primary source, with table or page.
- **D (derived):** computed from verified inputs by a stated formula in a script.
- **A (assumption):** declared and referenced, with a sensitivity where it matters.
- **N (numerics):** a solver setting, justified by convergence tests.

Gate 1 requires no input left unverified. The country table is generated by `data/build_country_table.py` from the APIs and `data/manual_inputs.csv`, and `--check` compares it with the committed file.

## What changed in this audit, and why

1. **Education shares were 50/50 for every country.** SAGEConfig's default was never overridden. Now per country.
2. **alpha and B were thesis values carried over.** Now from SES and EU-SILC, with mean 1.
3. **The effort target mixed an all-adult INSEE level with HETUS employed ratios.** Now HETUS employed throughout.
4. **median_to_mean was France's for every country.** Now per country.
5. **The German ratio 0.574 had no source.** Now 0.546. The French ratio measured membership; now volunteering (0.561).
6. **The income process is now anchored to a named estimate:** rho 0.92.
7. **Dread (agency version 2) was added,** with parameters from the literature.

Every change enters through `country_config`. The SAGEConfig defaults are untouched, so the suite's fixed reference economies (the preflight and test 15) still reproduce the old numbers exactly.
